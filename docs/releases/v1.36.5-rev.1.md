# SD Immutable Installer v1.36.5-rev.1

Welcome to the release of version v1.36.5-rev.1 of the Immutable installer for the [`SIGHUP Distribution`](https://github.com/sighupio/distribution) maintained by SIGHUP by ReeVo team.

This release updates Flatcar to 4757.2.3 and etcd to 3.6.16 for Kubernetes 1.36.5 and 1.35.9. It removes Kubernetes 1.35.5 and 1.34.8.

## Breaking Changes 💔

- The installer no longer has the packages for Kubernetes 1.35.5 and 1.34.8. No SD release uses these versions with this installer. SD 1.35.0 and 1.35.1 use Kubernetes 1.35.5 with installer v1.35.5 and v1.35.5-rev.2, and these releases do not change.

## Bug Fixes 🐛

- [[#45](https://github.com/sighupio/installer-immutable/pull/45)] keepalived: the control-plane virtual IP address now moves to another node when the Kubernetes API server stops. Before this release, the API health check did not run on Flatcar 4757.2.1 or later, because `/etc` does not let programs run from it.
- os-upgrade: the upgrade no longer stops on a node that enables a Flatcar extension in `/etc/flatcar/enabled-sysext.conf`, for example the NVIDIA driver extension `nvidia-drivers-570-open`. Before this release, `flatcar-update` refused to stage the new Flatcar version on these nodes. Now the upgrade downloads each enabled extension for the new version from the Flatcar update server, through the proxy of the cluster, and the node boots with it.

## New features 🌟

- [[#50](https://github.com/sighupio/installer-immutable/pull/50)] containerd: the containerd configuration now imports each `/etc/containerd/conf.d/*.toml` file. To add containerd settings to a node, for example a runtime, write a drop-in in this directory with the `storage.files` of the node. During an upgrade, the new configuration takes effect when the node reboots.
