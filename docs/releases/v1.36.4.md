# SD Immutable Installer v1.36.4

Welcome to the release of version 1.36.4 of the Immutable installer for the [`SIGHUP Distribution`](https://github.com/sighupio/distribution) maintained by SIGHUP by ReeVo team.

This release adds support for Kubernetes 1.36.4 and 1.35.8. Both versions use Flatcar 4757.2.0 and a new set of packages. Kubernetes 1.35.5 and 1.34.8 keep the packages of the previous release.

## Breaking Changes 💔

None

## Bug Fixes 🐛

- [[#24](https://github.com/sighupio/installer-immutable/pull/24)] kube-control-plane: the installer now creates users that have a space in the name. Before this release, the command that writes the kubeconfig file failed for these users.
- [[#26](https://github.com/sighupio/installer-immutable/pull/26)] The `keepalived` role now aligns its system extension during an upgrade. No role did this before, so the load balancers kept the keepalived version of the installation after an upgrade.
- [[#26](https://github.com/sighupio/installer-immutable/pull/26)] The `sysctl` role now loads the kernel parameters with `sysctl --system` only. The command held `-p` as well, which reads `/etc/sysctl.conf`. Flatcar does not give that file, so the task stopped the apply on every host of a new cluster.

## New features 🌟

- Kubernetes 1.36.4 and 1.35.8 are now available. Both run on Flatcar 4757.2.0 (Linux kernel 6.12.109), with containerd 2.3.6, etcd 3.6.15, keepalived 2.4.3, and HAProxy 3.2.23.
